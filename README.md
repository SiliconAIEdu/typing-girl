# Luna & Keys

A little practice. A little magic.

面向约 9–12 岁、也允许更小孩子按能力起步的小猫打字游戏。暖白、柔粉与淡紫；导航和标题以中文为主，英文名作为小字点缀。仓库名为 `typing-girl`，产品名为 Luna & Keys。独立项目，不修改原版 Kick & Keys 的代码或存档。

## 运行

无需安装依赖。macOS 可以双击项目中的 `启动游戏.command`，在浏览器访问 http://127.0.0.1:4178 。关闭启动窗口中的服务后，游戏页面将不能重新加载。

也可以在项目目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

有 Node.js 22 或以上版本时：

```sh
npm run dev
npm test
npm run build
```

`dist/` 是可发布到普通静态托管或 GitHub Pages 的完整网站。所有资源使用相对路径，支持任意仓库子路径。不要直接双击 `index.html`：浏览器通常不允许 `file://` 加载 ES modules。

## 已实现

- **My Studio**：今日进度、推荐练习、未完成课程续练。
- **Key Trails**：16 节键盘课程，从 F/J 与空格逐步扩展到数字、标点、Shift；另有 30 秒、60 秒检查和真实退格修改练习。
- **Story Garden**：16 个主题，词汇积累、短语与句子、文章阅读共 48 关；192 个词汇条目、192 条搭配与句子、32 篇原创文章，逐句中文提示、朗读和文后理解题。
- **Word Atelier**：12 个主题、36 关加 1 节拼音起步；144 个词语、120 条短语与句子、24 篇原创文章，支持中文输入法和文后理解题。
- **Little Surprises**：3 个卡池，自动撕包装、揭卡，也可跳过动画。
- **My Collection**：36 张小猫卡片，每张有中文名和一句小故事；珠光、镭射系列有不同的卡框。系列筛选、详情和心选收藏；获得的卡片可以“陪我练习”，替换练习页的陪练形象。
- **My Journey**：准确率与速度趋势、最需要多练的键、给家长看的一周小结（可打印 / 存为 PDF）、提示与音效设置、进度码和存档文件的导出与恢复。

## 练习与奖励

每节键位练习约 110–150 次按键：先单独认识新键，再和已学键、易错键混合，最后打只用已学字母组成的真实单词。数字课把数字放进“7 apples”这样的短语，标点课在词后练逗号、句号和问号，大写课覆盖全部 26 个大写字母。重练会产生新变体。词汇一轮覆盖本主题 12 个词；短语句子先练搭配再练完整句子，一轮覆盖全部条目。文章可自行选择，句子始终按原文顺序排列；读过的文章会标记，未完成的内容可暂停续练。

键位课准确率达到 80% 即算通过，首页推荐随之前进到下一课；结算页的主按钮是“下一课”。提示默认开启，并会逐步撤除：同一课上次准确率达到 90%，下次开始时自动收起指法提示；连续按错两次，Luna 会临时亮出当前键。“已熟练”需要两次准确率至少 90%、且看着提示按下的键不超过 20%。结算页显示速度、与上次的对比和易错键，成长足迹显示速度趋势和最需要多练的键；没有速度门槛和排行榜。

英语和中文课按键位进度软解锁：需要的键还没学完时，会建议先去练对应的键位课，也可以选择“我已经会打字了”直接开始（之后不再提醒，可在练习设置里改回）。中文练习使用系统输入法；修改练习保留错误，使用 Backspace 修正后 Enter 提交。

同一天同一课只发一次奖励：完成奖励按有效按键计算，每 10 次约 1 钻石，一课 5–30 钻石（中文每个字按 3 次按键计）；准确率至少 90% 额外 5，首次完成额外 10。当天完成 3 节不同课程再加 15。每天按北京时间零点划分。复习不扣钻石，也不会重复领取当日奖励。

## 内容与保存

中英文文章均为本项目原创，没有复制《新概念英语》或 IELTS 真题。课程按主题和词汇→短语句子→文章的顺序呈现，不设置简单/困难选择器。英语文章每篇 83–129 词，中文文章约 200–241 汉字，每个主题有两篇可选择的文章。主题包括日常生活、动植物、海洋、天气、地图、科学实验、合作与数字素养。内容包含具体情节、观察和问题解决，仍需通过真实学生试用继续调整。建议从能理解的词语和句子开始。

进度存储在当前浏览器的 localStorage，键名 `luna-and-keys:v1`。不含账号、服务器和自动跨设备同步。浏览器、域名或端口改变时，需要手动导入备份；清除浏览器数据会清除进度。更换设备前到成长足迹“复制进度码”，在另一台电脑“粘贴进度码”；也可以导出存档文件。恢复前会保留一份本地备份，可点击“找回恢复前的记录”。建议一次使用一个游戏页面。

练习时有轻声的按键音效（可在练习设置关闭）、连击计数和 Luna 的小反应；大写锁定开着时会提示先关掉。中文课在每个字上方显示拼音，可以收起；中文与修改练习收起键盘图，把空间留给输入框。

按键练习面向有实体键盘的电脑，手机首页会提示这一点。窄屏可浏览课程与收藏，中文输入框也适配窄屏，但手机虚拟键盘并非完整打字训练替代品。切换窗口、隐藏页面或按 Esc 会暂停；未完成课程保留输入位置。

练习页把输入内容、键盘与双手指法放在同一屏。双手画成两只白色小猫爪，四颗肉垫对应小指到食指，旁边的小肉垫对应拇指。每根手指有自己的颜色，键盘上每个键也带着负责它的手指颜色；要按哪个键，对应的肉垫就亮成那个颜色并放大，其他肉垫变淡，键也亮成同一种颜色。大写及组合标点同时亮起对侧小指和 Shift，空格亮起拇指。隐藏指法后不自动报出字母；主动听字母算作使用提示。

键位课自动朗读下一个字母；英语词句和中文课支持朗读。右上角“声音与试听”默认使用 Heart 美式女声，课程音频随网站发布，速度 1.0。也可手动选择设备英语声音；中文自动使用设备普通话声音。设备朗读语速 0.86。切换题目或暂停会停止旧声音，播放失败时提供重试提示。

界面使用 Google Fonts 的 DM Sans / Noto Sans SC，无法联网时回退到系统字体；英语录音通过浏览器播放，中文朗读依赖设备语言声音，可随时关闭。图片已随项目打包，无需图片外链。没有分析追踪脚本。

## 开发位置

- `src/content.js`：课程结构、兼容旧存档的关卡 ID、卡池及卡片。
- `src/english-curriculum.json`、`src/chinese-curriculum.json`：原创语言内容；修改后运行 `npm run content` 更新生成的 `curriculum-data.js`（dev/test/build 已自动包含这一步）。
- `src/engine.js`：练习生成、判定、奖励、推荐与解锁、抽卡和备份校验。
- `src/drills.js`：键位课生成（新键 → 混合 → 真实单词）与单词表。
- `src/app.js`：界面与键盘、输入法、暂停和保存交互。
- `src/style.css`：通用响应式样式与拆包动画。
- `src/practice.css`：以文字、键盘和双手为中心的练习布局。
- `src/fingering.js`：完整双手图、键位与手指和对侧 Shift 映射。
- `src/voice.js`：声音选择、异步加载、试听和过时提示取消。
- `src/sfx.js`：用 Web Audio 合成的按键音效，不加载音频文件。
- `src/pinyin-data.js`：由 `scripts/generate-pinyin.mjs` 生成的中文课拼音。
- `public/art/`：网站使用的 WebP 插画（约 440 KB）。PNG 原图保存在 `art-source/`，由 `scripts/optimize-images.mjs` 转换。
- 制作工具（不随网站发布）：`npm install --prefix scripts/assets` 后运行 `node scripts/generate-pinyin.mjs` 或 `node scripts/optimize-images.mjs`。
- 代码使用 Prettier 格式化（`.prettierrc`）。
- `tests/engine.test.mjs`：课程范围、重复结算、熟练规则、抽卡、备份等核心测试。

完整源码与生成音频保存在下列 GitHub 仓库。
